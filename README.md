# Todo App

I made a todo list app with a Go API and a small web page. I can add a task, tick it off, change it, or delete it.

Tasks are saved in a little SQLite file, so they are still there when I come back. Each task has a title, and I can also add a note, a priority, a due date and a category if I want.

To run it, type go run . and open localhost:8080 in a browser.
